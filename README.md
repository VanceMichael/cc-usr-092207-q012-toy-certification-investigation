# 玩具认证冒用排查

排查玩具认证编号冒用并追踪涉案批次的销售与召回。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括认证执法人员、认证机构、玩具生产企业、经销门店、消费者通知人员。

资料所依据的领域事实如下：

- 涉案玩具包装印有CCC标志，扫码后指向另一型号产品的证书
- 排查需区分包装返工失误与多型号共用证书的系统性冒用
- 涉案产品由生产企业供货至多家门店销售
- 监管部门根据仓库实物、流向记录和已售数量作出处置

## 资料结构

- `certificates`：证书版本与核定产品范围，是判断冒用的基准
- `timeline`：证书范围、包装版本、生产入库、供货门店、销售记录、扫码上报、抽样照片、询问笔录、跨地区补报、整改补交、处置决定等事件，按发生时间互相印证，引用不得指向更晚发生的事件
- `lots`：以批次标识的具体实物及其当前责任门店
- `reports`：批量扫码与跨地区补报，合并来源时同一实物只计一次，不得重复计入
- `certificate_status`：证书暂停、恢复或换绑的记录独立保存，不改写市场事实时间线
- `notices`：门店应下架与通知的范围，不得超出门店自身持有批次
- `dispositions`：处罚或解除措施，必须指向具体实物、证书版本、流向与消费者触达结果

企业补交的整改材料以时间线事件追加，执法材料不得删除。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实、约束、时间线互证、实物批次、上报合并、证书状态、通知范围与处置指向。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
